# My agent: Smart Marketplace Concierge (LifeMart Agent)
One-liner: A conversational agent that helps everyday consumers discover, budget, and manage essential daily living products with intelligent pantry replenishment, bundle recommendations, and interactive rich catalog UI.

Tool coverage:
- Memory: Remembers household dietary preferences, allergies, recurring shopping list habits, budget limits, and frequently purchased essentials.
- Tools: Search and filter inventory, check real-time stock and prices, calculate smart basket discounts/bundles, add items to cart, and track replenishment schedules.
- Catalog/UI: Rich catalog cards for everyday essentials (groceries, household goods, personal care), comparative price/nutrition tables, and interactive shopping cart checkout cards.
- Image gen: Generates visuals of customized meal kits, product bundles, or eco-friendly living setups.
- Sandbox: Computes complex bulk-buy savings, unit-price comparisons, and monthly household budget forecasts.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for budget/discount optimizations, Firestore for real-time inventory management, A2UI cards for interactive category browsing and basket checkouts.
